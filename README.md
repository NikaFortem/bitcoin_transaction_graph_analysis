## ML approach for transactional analysis of crypto network users

### Описание проекта

Проект посвящен анализу структуры транзакционного графа сети Bitcoin с применением методов графового машинного обучения.

Цель работы — исследовать и сравнить различные подходы к выявлению сообществ и структурных закономерностей в транзакционной сети Bitcoin, а также оценить устойчивость полученных результатов на различных временных интервалах.

---

### Архитектура исследования

```text
On-chain данные Bitcoin (Google BigQuery)
                │
                ▼
Формирование выборки транзакций
                │
                ▼
Построение транзакционного графа
(вершины — транзакции, ребра — связи UTXO)
                │
                ▼
Расчет графовых характеристик
(degree, in-degree, out-degree, PageRank)
                │
                ▼
Методы анализа графа:
────────────────────────────────────────
│ Classical Graph Metrics + HDBSCAN  │
│ Node2Vec + HDBSCAN                 │
│ Louvain Community Detection        │
│ GraphSAGE + features               │ 
│ Structural GraphSAGE               │
────────────────────────────────────────
                │
                ▼
Оценка качества кластеризации
(Silhouette, Davies–Bouldin,
Calinski–Harabasz, Modularity)
                │
                ▼
Анализ устойчивости во времени
(5 недельных срезов 2026 года)
                │
                ▼
Интерпретация экономической структуры сети
```

### Установка и запуск проекта

#### 1. Установка зависимостей

Перед запуском проекта необходимо установить все требуемые библиотеки:

```bash
pip install -r requirements.txt
```

#### 2. Проверка структуры данных

Убедитесь, что все входные данные находятся в правильной директории проекта:

```text
data/
```

Важно:
- папка `data/` должна находиться в корне проекта
- все необходимые файлы должны быть внутри `data/`

---

#### 3. Запуск проекта

Основной пайплайн запускается через Jupyter Notebook:

```bash
jupyter notebook main_pipeline.ipynb
```

или:

```bash
jupyter lab
```

После запуска выполняйте ячейки последовательно сверху вниз.

---

#### 4. Результаты выполнения

После выполнения всех этапов папка с результатами создаётся автоматически:

```text
monthly_week_results/
```

В неё сохраняются:
- результаты кластеризации
- итоговые таблицы сравнения методов

### Этапы исследования

#### Этап 1 — сравнение методов на базе основного экспериментального периода
- формирование транзакционного графа Bitcoin  
- анализ топологии сети и распределения степеней  
- расчет графовых характеристик узлов
- применение методов:
  - Classical Graph Metrics + HDBSCAN  
  - Node2Vec + HDBSCAN  
  - Louvain Community Detection  
  - GraphSAGE + features
  - Structural GraphSAGE  
- сравнение качества кластеризации

#### Этап 2 — анализ устойчивости результатов во времени
- анализ устойчивости на 5 временных срезах  
- интерпретация экономической структуры сети  

---

### Результаты:
- Транзакционная сеть Bitcoin демонстрирует многоуровневую структуру.
- Количественные характеристики ключевых уровней сети воспроизводятся на всех 5 исследованных недельных срезах, охватывающих рост абсолютного объема транзакций на 65%.
- Рассмотренные методы не являются взаимозаменяемыми и описывают разные уровни организации сети. Это подтверждает эффективность комбинированного подхода к анализу транзакционной сети Bitcoin.
- Вычислительная сложность модели не является определяющим фактором качества. Простые топологические характеристики узлов несут значительный объем информации о структуре сети.
